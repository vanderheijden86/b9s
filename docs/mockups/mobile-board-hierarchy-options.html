Mobile board: showing the hierarchy

Today the epic rail on the phone is a filter, and its all state is a flat list sorted by priority. A card's parent is visible only as an ID prefix, and a parent that is not an epic (a task with subtasks) is never shown. The four phones below use the Open column from the screenshot: 25 cards across foit, 6e8h, bjqc and 17 loose cards.

Recommendation: option 1, with option 2's parent line for nested cards

Option 1 keeps the rail the user already knows and makes it useful in the all state: tapping an epic scrolls to its lane, the header sticks while its cards scroll past, and the rail highlights the lane in view. It is the smallest change, because epic rows already exist on the phone and the wide board already assigns each epic a hue. A lane only knows the topmost epic, so a subtask of a task (b6jw.4) still needs one line naming its direct parent, which is option 2's third line, drawn only when the parent is not the lane's epic.
