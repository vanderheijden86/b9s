Five light modes for b9s

The light theme b9s ships today is the dark theme inverted onto pure white. Black text on #FFFFFF sits at 21:1 contrast and turns the whole terminal into a lamp. These five options lower the background brightness and the text contrast, and keep every text colour at or above WCAG AA (4.5:1).

Each option is the real tree view with the same issues, so only the palette changes. The current theme is at the end for comparison.
