Memories and Issues as one graph

Five ways to show which work uses which decision. All five draw the same data: the 13 ADR Memories, 20 Issues, 20 decision Links and one supersedes Link from the b9s Memory POC, plus the epic hierarchy. Three problems sit in that data, and each mockup should make them obvious: vd9g.1.6 follows ADR 0009, which 0027 replaced. Four xx9w features follow ADR 0026, which is still proposed. n0wb and 36s record no decision at all.
